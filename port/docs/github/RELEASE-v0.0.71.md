# Silent Scope v0.0.71 — Quest

Fixes pointer interaction in the original **Main Menu → Options** screen.

- Settings remain selectable after changing values, including Continue's special setting.
- Selected rows, highlighted values and the game's moving adjustment arrows remain interactive.
- Category changes from lower rows finish instead of timing out while returning to the heading.
- The original game menu and purple −/+ controls share the current native Options page.

Point at a setting's row, then pull Trigger on the game's arrows or purple **−/+** controls to adjust it. Point at a category tab and pull Trigger to change pages.

The user confirmed the corrected Options controls work on Quest 3. All **77 production/graphics checks** pass. This is an in-place update to the existing app: your settings and imported game files are preserved.

Download **silent-scope-vr-quest.apk** for standalone Quest 3 / 3S. You must supply your own supported Silent Scope (USA) Dreamcast CUE and three BIN tracks; see the [project page](https://github.com/vr4all-standalone/silent-scope-vr#your-game-files).

The release includes the complete matching source and SHA256 checksums. Use **silent-scope-vr-source.zip** for the engine, dependencies, adapter and build instructions; GitHub's automatic source archives contain the page and adapter.

This Options repair does not add the previously unsupported memory-card operations. The broader continuous campaign and every result screen have not been fully verified. PCVR is not shipped in this release.
