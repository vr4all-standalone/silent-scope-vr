# Silent Scope v0.0.68 — Quest

First public Quest release of Silent Scope VR, using the owned US Dreamcast version.

- Immersive stereo scenery, wider view, and a tracked rifle with the game's independent live scope camera.
- Arcade and AWP Simulation rifles available in front of the player.
- Two-hand aiming, adjustable smoothing and scope stability, hold-to-Focus, and native scope zoom.
- Simulation bolt and magazine interaction, cartridge loading, casing ejection, and shot-confirmed recoil and haptics.
- Pointer controls for the original game menus, VR4ALL settings and controller help, and a four-picture startup guide.
- Stereo fixes for the Woods searchlights and the Hotel Imperial target radio message.

Download **silent-scope-vr-quest.apk** and install it on Quest 3 or Quest 3S. Supply your own Silent Scope (USA) US V1.000 CUE and all three matching BIN tracks through the app's setup picker. The [project page](https://github.com/vr4all-standalone/silent-scope-vr#your-game-files) lists the required filenames and controls.

The signed APK preserves the existing preview package identity and app data when installed as an update. SHA256SUMS.txt identifies the published APK and source archive.

**Experimental.** The build is installed and hash-verified on Quest 3S and its startup screen was launched successfully. Native Windows replays covered the Story stages, both Night Vision routes, the three Time Attack entries, Indoor and all Outdoor Shooting Range stages. The 77 host/GPU checks pass. A continuous scored campaign, every results screen and the latest complete headset playthrough remain unverified. Loading and view changes can briefly use the original flat view.

Use **silent-scope-vr-source.zip** for the complete matching engine, dependency sources, Android framework, adapter, models and build instructions. GitHub's automatic source archive contains the project page and adapter. This is the standalone Quest release.
