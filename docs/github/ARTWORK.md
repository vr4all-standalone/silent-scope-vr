# Artwork provenance

The banner uses original Silent Scope Dreamcast Japanese front-cover artwork, credited to Konami. The scan is hosted by MobyGames.

- [Cover page](https://www.mobygames.com/game/3829/silent-scope/cover/group-28508/cover-74850/)
- [Source image](https://cdn.mobygames.com/covers/4602845-silent-scope-dreamcast-front-cover.jpg)

The cover is resized proportionally on the right of the established VR4ALL grid, title and platform layout. The underlying game artwork, logos and trademarks remain with their owners.

The startup instruction pictures use the project's supplied rifle models and the credited controller models in the app's model credits.
